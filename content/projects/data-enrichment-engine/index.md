## Context

Driving data is only useful for model development if teams can find the right situations in it.

## My role

As an Autonomous Driving Software Engineer, I developed core components of a data enrichment engine that adds three kinds of searchable signals:

- **HD-map labels**
- **Signal-grounded vision-language model (VLM) annotations**
- **Image-text embeddings**

## Outcome

- **100,000+ hours** of driving data made searchable.
- Enabled scenario discovery, similarity search and targeted data curation.
